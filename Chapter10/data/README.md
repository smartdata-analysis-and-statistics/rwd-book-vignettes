# Chapter 10 teaching dataset

The practicals use a simulated comparative-effectiveness study of dimethyl fumarate (`DMF`) versus teriflunomide (`TERI`) in 3,000 patients with multiple sclerosis. The outcome `y` is the number of relapse episodes over a patient-specific follow-up period (`years`). The baseline variables include age, gender, previous disease-modifying treatment efficacy (`prevDMTefficacy`), log premedical cost (`logPremedicalcost`), prior relapse count (`prerelapseNum`), and symptom count (`numSymptoms`). Treatment assignment depends on baseline characteristics, so the data illustrate confounding. Values are deliberately missing in selected covariates for the missing-data exercises.

Both the data-preparation practical and the homogeneous treatment-effect practical load the same file, [`chapter10_exploration_data.rds`](../Practicals/data/chapter10_exploration_data.rds). It contains 3,000 records with missing age (92), log premedical cost (346), and previous relapse count (94). The fixed data were generated under the helper's `MAR_COVARIATE` scenario: missingness depends on fully observed treatment, gender, symptom count, outcome, and follow-up. `chapter10_homogeneous_data.rds` is kept as an identical compatibility copy; the practicals should use the shared exploration file. The generator and missingness functions are in [`Practicals/chapter10_helpers.R`](../Practicals/chapter10_helpers.R). These are simulated patient-level records, not data from actual patients.
